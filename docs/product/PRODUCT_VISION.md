# Orva Product Vision

## Product statement

Orva is a local-first personal growth system that helps a person align daily behavior with long-term intentions. It turns plans into observable opportunities, activities into evidence, evidence into understandable progress, and progress into milestones.

Working promise: **Build the person you want to become.**

This is not a claim that software can measure a person's full identity, worth, health, or character.

## Core loop

1. Define goals, missions, routines, and meaningful behaviors.
2. Plan realistic time and recurring opportunities.
3. Execute and record real activity with minimal friction.
4. Understand the gap between planned and actual activity.
5. Reflect using the user's selected Beto/Alfredo archetypes.
6. Improve the next plan and unlock meaningful milestones.

## Product pillars

### Command center
Today and Android widgets should answer: What matters today? What is next? What remains? What did I actually complete?

### Planning and execution
A real day/week/month calendar with recurring time blocks, exceptions, actual execution records, and a clear visual distinction between plan and fact.

### Behavioral comparison
A fixed pair:
- Alfredo: default archetype for behaviors the user wants to strengthen.
- Beto: default archetype for behaviors the user wants to reduce or avoid.

Users may personalize the presentation and traits/rules. The result measures selected behavior in a stated period; it is not the user's permanent identity.

### Missions and progression
Manual and record-integrated missions. XP, levels, achievements, and prestige provide secondary progression. Rewards must be meaningful, explainable, and resistant to farming.

### Honest analytics
Metrics use explicit denominators, windows, evidence sources, and exclusions. Missing data remains unknown. Planned time is not actual time.

### Personal data ownership
Core data remains local and usable offline. Export is deliberate. External services/AI are optional and require clear consent.

## Desired experience

Focused rather than noisy. Sophisticated rather than childish. Game-inspired without manipulation. Data-informed without pretending every behavior is perfectly measurable. Fast for daily actions and deep for reviews. Private by default.

## Non-goals

Orva is not intended to diagnose addiction, mental health, personality, or medical conditions; shame missed activities; equate productivity with personal worth; reward app opens or meaningless taps; require social competition; force cloud accounts; expose journal/health/finance details in widgets; or build every future module before the core loop is reliable.

## Product language

User-facing copy: concise Brazilian Portuguese. Code, schemas, internal identifiers, technical docs, and agent prompts: clear English by default.

## Success criteria

- The user understands today's priorities quickly.
- Planned and real execution are connected but distinct.
- One activity updates every relevant projection exactly once.
- Beto/Alfredo scores are explainable from records and rules.
- Recurring missions work across period boundaries.
- Widgets show useful, safe, fresh information.
- Analytics inform planning without misleading.
- Users can export and preserve personal data.
- Core features work offline.
